plainpy runs Python 3.14 programs and compiles typed ones into small native executables, or into C for microcontrollers. One C codebase written from scratch, with nothing to install but itself.

Ubuntu 22.04, 24.04, 26.04 · amd64, arm64 · updates with apt

$ sudo add-apt-repository ppa:c4simba/plainpy$ sudo apt install plainpy

Debian 12+, Ubuntu · the .deb of the latest release (arm64: plainpy_arm64.deb)

$ curl -LO https://github.com/c4simba/plainpy/releases/latest/download/plainpy_amd64.deb$ sudo apt install ./plainpy_amd64.deb

Fedora, RHEL, openSUSE · the .rpm of the latest release (arm64: plainpy.aarch64.rpm)

$ curl -LO https://github.com/c4simba/plainpy/releases/latest/download/plainpy.x86_64.rpm$ sudo dnf install ./plainpy.x86_64.rpm

Apple silicon · unpack anywhere, it finds its files next to itself

$ curl -L https://github.com/c4simba/plainpy/releases/latest/download/plainpy-macos-arm64.tar.gz | tar xz$ ./plainpy-*/bin/plainpy --version

Any Unix with a C compiler and make

$ git clone https://github.com/c4simba/plainpy && cd plainpy$ make && sudo make install

Why plainpy

    
Small on purpose. Python all the way down.

    
No interpreter to install first, no virtual environment, no toolchain zoo. A parser, an interpreter, a compiler and a standard library, written to be read and carried around.

    

      

        
01

        
Nothing else to install

        
The interpreter needs the C library and nothing more. It builds with a C compiler and make, and finds its files next to itself: unpack a folder anywhere and it runs.

      

      

        
02

        
All of Python’s syntax

        
The parser follows CPython 3.14’s grammar and builds its ast tree: f-strings with format specs, decorators, keyword-only parameters, every statement. A program reads exactly as CPython reads it.

      

      

        
03

        
Interpret it, or compile it

        
Run any program with plainpy. Give it types and plainpy --compile makes a native executable: i386 Linux and KolibriOS through fasm, macOS through the C compiler.

      

      

        
04

        
A standard library in Python

        
97 modules — json, re, datetime, logging, unittest, threading, http.server, tomllib and more — written in Python, for the interpreter and compiled programs alike.

      

      

        
05

        
Packages from PyPI

        
plainpy add, lock and sync keep pyproject.toml and pylock.toml without a virtual environment, and check which pure-Python packages compiled programs may use.

      

      

        
06

        
FastAPI, compiled

        
FastAPI’s own hello world compiles unchanged into a 28 KB Linux executable that serves HTTP: routes, path and query parameters, JSON, and the 404, 405 and 422 answers FastAPI gives.

      

      

        
07

        
Memory without a runtime

        
Compiled code counts references only where the compiler can’t prove a count doesn’t matter, and a cycle collector frees the garbage that reference counting can’t.

      

      

        
08

        
Down to microcontrollers

        
--target c writes the program as portable C that needs no C library; --target esp32 makes an ESP-IDF project. machine drives pins, PWM, ADC, I2C, SPI and UARTs, and ctypes calls the board’s SDK.

      

      

        
09

        
At home on KolibriOS

        
The interpreter, the compiler and the programs it makes run on KolibriOS, an operating system written in assembly. There it compiles with the system’s own fasm.

      

    

  






  

    
Two modes

    
The same file. Interpreted, or a binary.

    
Write ordinary typed Python. Run it straight away while you work on it, then compile it into an executable that runs fast and on its own, without plainpy beside it.

    

      

        
fib.pyPython 3.14


def fib(n: int) -> int:
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a

print([fib(i) for i in range(12)])
print(fib(90), 2 ** 40)

$ plainpy fib.py                    # interpreted

Speed

    
Compiled, it outruns CPython on all but one.

    
make bench runs plain-Python programs under CPython 3.14 and compiled by plainpy, the best of three runs each, and checks that their outputs match.

Install

    
Pick your system. It takes a minute.

    
Every release is built by GitHub Actions, and the packages are installed and run on clean Debian, Ubuntu and Fedora first. The links always point at the latest one.

    

      

        
Ubuntu PPA on Launchpad · 22.04, 24.04, 26.04 · amd64, arm64

        
Launchpad builds plainpy from source for each Ubuntu release, and apt upgrade brings the new versions.

        


$ sudo add-apt-repository ppa:c4simba/plainpy$ sudo apt install plainpy

          
        

        
No add-apt-repository? sudo apt install software-properties-common. The archive: launchpad.net/~c4simba/+archive/ubuntu/plainpy

      

      

        
Debian, Ubuntu .deb · amd64, arm64

        
One package from the latest release, for Debian 12 and newer and any Ubuntu since 22.04.

        


$ curl -LO https://github.com/c4simba/plainpy/releases/latest/download/plainpy_amd64.deb$ sudo apt install ./plainpy_amd64.deb

          
        

        
ARM: plainpy_arm64.deb. Remove with sudo apt remove plainpy.

      

      

        
Fedora, RHEL, openSUSE .rpm · x86_64, aarch64

        
One package from the latest release; on openSUSE install it with sudo zypper install.

        


$ curl -LO https://github.com/c4simba/plainpy/releases/latest/download/plainpy.x86_64.rpm$ sudo dnf install ./plainpy.x86_64.rpm

          
        

        
ARM: plainpy.aarch64.rpm. Remove with sudo dnf remove plainpy.

      

      

        
Any Linux tarball · x86_64, aarch64

        
No package manager, no root: bin/ and lib/plainpy/, unpacked wherever you like.

        


$ curl -L https://github.com/c4simba/plainpy/releases/latest/download/plainpy-linux-x86_64.tar.gz | tar xz$ ./plainpy-*/bin/plainpy --version

          
        

        
ARM: plainpy-linux-aarch64.tar.gz.

      

      

        
macOS tarball · Apple silicon

        
Compiled programs are native arm64 executables, built through the system’s C compiler.

        


$ curl -L https://github.com/c4simba/plainpy/releases/latest/download/plainpy-macos-arm64.tar.gz | tar xz$ ./plainpy-*/bin/plainpy --version

          
        

      

      

        
KolibriOS zip

        
plainpy, plainpyc, plainpy.lib and lib/ in one folder: put it anywhere on the system and run it from the shell.

        


$ curl -LO https://github.com/c4simba/plainpy/releases/latest/download/plainpy-kolibrios.zip

          
        

      

      

        
From source a C compiler and make

        
Installs into /usr/local; PREFIX= chooses another place, make deb and make rpm build the packages.

        


$ git clone https://github.com/c4simba/plainpy && cd plainpy$ make && sudo make install

          
        

      

    

    
Running programs needs nothing more. Compiling them, plainpy --compile, needs fasm for the Linux and KolibriOS targets (sudo apt install fasm) or a C compiler for macOS; plainpy add downloads packages with curl.
